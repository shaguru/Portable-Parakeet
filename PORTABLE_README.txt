Parakeet Dictation - portable Windows build

1. Extract the entire ParakeetDictation folder to your Desktop, USB drive,
   or any writable folder. Do not run it inside the ZIP.
2. Double-click ParakeetDictation.exe. Keep the folder contents together.
3. Click where you want text, hold Win + Alt, speak, then release either key.

No installation, Python, administrator rights, Murmur, or account is required.
Speech is processed locally. The CPU runtime works without NVIDIA drivers.
The model is about 428 MB; allow roughly 600 MB for the extracted folder.

Microphone: uses your Windows default input device (or a USB PnP microphone,
if present). Windows must allow desktop apps to use the microphone.

Cleanup removes hesitation sounds and clear filler uses of "like" while
preserving ordinary preferences and comparisons.

On an organisation-managed PC, application restrictions may prevent any
unapproved EXE from running. This package does not bypass those restrictions.

Temporary audio is written to your user's temporary folder and removed after
transcription. The app does not register itself for startup or install files.
